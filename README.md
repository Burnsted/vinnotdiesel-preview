# VinNotDiesel Preview

Public static web preview of **VinNotDiesel** — a used EV work-truck marketplace.

> Used EV work trucks. Battery first.

## Stack

- Vite + React (JSX)
- Hash router (GitHub Pages friendly)
- Base path: `/vinnotdiesel-preview/`

## Local

```bash
npm install
npm run dev
npm run build
```

## Demo inventory

Seed listings are fake. Footer labels the site as demo inventory. No payments.
