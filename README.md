# FleetFit Preview

Public static web preview of **FleetFit** — small-fleet used EV packages (Acquire), not a one-off auction board.

> Used EV fleet packages that fit the work day.

## Stack

- Vite + React (JSX)
- Hash router (GitHub Pages friendly)
- Base path: `/vinnotdiesel-preview/`

## Local

```bash
npm install
npm run dev
npm run build
```

## Demo inventory

Seed listings are fake. Footer labels the site as demo inventory. No payments.
